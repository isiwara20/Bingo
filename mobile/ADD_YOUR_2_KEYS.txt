STEP 1: Get 2 real API keys from Google
────────────────────────────────────────

1. Open: https://aistudio.google.com/app/apikey

2. Sign in with Google

3. Click "Create API Key" - TWO TIMES (to get 2 keys)

4. Copy both keys - they should look like:
   AIzaSyDh4qF5Xx-XxXxXxXxXxXxXxXxXxXxXxX
   ^^^^^^ Notice it starts with "AIza"


STEP 2: Edit mobile/.env file
──────────────────────────────

1. Open: mobile/.env in any text editor

2. Find these lines:
   GEMINI_API_KEY=YOUR_FIRST_API_KEY_HERE
   GEMINI_API_KEY_2=YOUR_SECOND_API_KEY_HERE

3. Replace with your 2 real keys:

   BEFORE:
   ┌────────────────────────────────────────────────────┐
   │ GEMINI_API_KEY=YOUR_FIRST_API_KEY_HERE            │
   │ GEMINI_API_KEY_2=YOUR_SECOND_API_KEY_HERE         │
   └────────────────────────────────────────────────────┘

   AFTER:
   ┌────────────────────────────────────────────────────┐
   │ GEMINI_API_KEY=AIzaSyDh4qF5Xx-XxXxXxXxXxXxXxXxX   │
   │ GEMINI_API_KEY_2=AIzaSyYYYYYYY-YyYyYyYyYyYyYyYyY  │
   └────────────────────────────────────────────────────┘

4. SAVE the file (Ctrl+S)


STEP 3: Test and rebuild
─────────────────────────

Open terminal and run:

┌────────────────────────────────────────────────────┐
│ cd mobile                                          │
│ npm run test:keys                                  │
└────────────────────────────────────────────────────┘

You should see:
✅ Valid keys: 2/2
🎉 All keys are valid!

Then rebuild:
┌────────────────────────────────────────────────────┐
│ npm run build:clean                                │
│ npm run build:apk                                  │
│ npm run install:apk                                │
└────────────────────────────────────────────────────┘
